# Evolução de skill

Proponha apenas método, decisões, gates e fronteiras reutilizáveis. Não copie autos nem dados do caso
para a skill. Uma ocorrência cria candidata ou ramo, não regra rígida. A proposta nasce vinculada à
tarefa aprovada. Somente o Controller a promove; skill existente nunca é sobrescrita silenciosamente.
