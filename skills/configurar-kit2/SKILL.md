# Configurar Kit 2

Leia `README.md`, audite o repositório e confirme que ele é privado antes de dados do escritório.
Execute `python3 euro.py configurar` internamente. Comece em sandbox. Solicite somente nome,
escritório, papel, agente e raiz local das entradas congeladas. Login GitHub ocorre pelo navegador;
nunca peça token na conversa. Execute `instalar-skills` e `preparar-auto-sync`; instale o arquivo de
agendamento gerado pelo mecanismo nativo do sistema, sem editar seu intervalo de dez minutos. Termine
com `diagnosticar`, rode uma sincronização de teste e traduza o resultado em checkpoints simples.
